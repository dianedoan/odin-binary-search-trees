# Binary Search Trees
This project consists of two classes:
- `Node` which has an attribute for the data it stores as well as its left and right children
- `Tree` which accepts an array when initialized and has a root attribute which uses the return value of `buildTree()`

## Description
This project demonstrates the skills learnt from the JavaScript Course in The Odin Project up until the [Common Data Structures and Algorithms](https://www.theodinproject.com/lessons/javascript-common-data-structures-and-algorithms) topic.
